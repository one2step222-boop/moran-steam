원문 보기

We’ve made a major change to the Mac version of Terracards in response to the persistent black screen issue many players have reported since release. To (hopefully) solve this, we’ve rebuilt the Mac version using a different compilation method. Previously, the game used GameMaker’s YYC compiler, but we’ve now switched to the VM build and made the Mac version completely DRM-free (since Steam is not supported in this compilation method). This change should resolve the black screen issue, but it comes with an unfortunate side effect: Steam achievements on Mac will no longer work. Instead, achievements will now be stored and tracked locally only. Because of this, all Mac achievements are being reset in this update. We know this may be frustrating, but we hope the improved stability—and being able to actually play the game!—makes up for it. For the curious or technical, you can check out the original bug report I made in the GameMaker forums "Draw" layer is simply black.
