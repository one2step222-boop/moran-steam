원문 보기

This version fixes a crash which some players get on launch, easy as 1-2-3. For those who are curious, here’s the problem: Our engine saves certain computer-specific settings like music volume or windowed/fullscreen choice in a special .prefs folder which is separate from the game save data. If this .prefs file couldn’t be accessed for some reason, the game would crash. Now, instead, if the file is inaccessible then we simply don’t save those choices. Unfortunately that means the game won’t remember these kinds of settings between sessions, but the game is otherwise fully playable as normal. To the player who reported this crash, thanks! ✨ -Darzington & Zalinius
