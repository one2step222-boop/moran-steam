RentPoly 1.0.23 Patch Notes

한글 요약이 품질 관문에 걸려 원문만 둡니다.

원문 보기

Fixed an issue where the rent amount of a tile would not immediately update after continuing a saved run. Added a failsafe dice roll value to saves. In the rare circumstance where the game fails to save/load a dice value, the player will roll a new random dice (within its given seed) instead of being stuck without a dice. Fixed an issue where Aluminum's extra credit gain would take too long if an incredibly high number of rerolls was obtained during the run. After a certain point, the result screen will immediately calculate the remaining extra credit. Added a maximum cap on credit (2,147,483,647), so it won't overflow into negative when earning more than that amount of credit. Added a maximum cap on rerolls (2,147,483,647), so it won't overflow into negative when earning more than that amount of rerolls.

한글 요약이 품질 관문에 걸려 원문만 둡니다.

원문 보기

Added victory markers for characters, maps, and difficulties in the select menu. It's a small crown icon (like in Compendium) in the top right corner, which keeps track of characters, maps, and difficulties you've got victories with. Adjusted the Multi Tool item to copy the original item's values. For instance, in the previous version, if the Multi Tool copied an Engine tool with +$500, it would still start with $0. With this change, the copied tool will have $500. This change was made to make it more distinct from other tool copying tool, which will not copy the item's values.
