This update fixes controller problems that were due to conflicts between the Steam UI and possible game controller overlay. Change details: - Updated to the latest Steamworks SDK (1.42) - Game is not paused (automatically) when changing to another window. Audio is paused, if game is being run in full screen. - Game controller detection now happens after the game launch screens. - Better support for situation where several game controllers are being connected / disconnected. - Bug fix for: "Ambient sound is not restored after window focus is regained" - Bug fix for: "Not possible to resume game after 'Game paused' using game pad".

Controller Support Problems: Workarounds

한글 요약이 품질 관문에 걸려 원문만 둡니다.

원문 보기

Hi! Many people are having trouble with controller support. This is typically due to the Steam UI conflicting with the game controller overlay. We are working on a fix to resolve this issue. In the meanwhile, if your game controller does not seem to be working, try any of the following steps (A, B or C): A. Turn off "Guide Button Focuses Steam" from your Steam settings. --------------------------------------------------------------------------------------------------- Details: (1) Click "Steam" menu from top left corner of the Steam app. (2) Select "Settings". (3) Select ”Controller”. (4) Select ”General Controller Settings”. (5) Untick ”Guide Button Focuses Steam”. or B. Start the game from the File Explorer (instead of the Steam app). --------------------------------------------------------------------------------------------------- Details: (1) From the Steam app, select “Library” >> “Games” and then choose “Oceanhorn…” from the list on the left. (2) Select Oceanhorn “Properties” with the right mouse button. (3) Select “Local Files” tab. (4) Select “Browse Local Files…”. (5) Double-click “Oceanhorn.exe”. or C. Disable the Steam overlay. ------
