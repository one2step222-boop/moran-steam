어떤 게임인가

한때 자랑스러웠던 컬렉션이 오랫동안 잊혀 있었습니다. 이제 본래의 모습으로 되돌릴 시간입니다. 카드를 한 장씩 집어 들고, 자세히 살펴보고, 깨끗이 닦은 뒤 알맞은 진열장에 보관하세요. 모든 카드에는 테마 세트, 아키타입, 희귀도가 있으며 포일 카드도 존재합니다! 방 안의 혼란이 조금씩 정돈된 갤러리로 바뀌는 모습을 편안하게 지켜보세요.

다행히 모든 카드가 더러워진 것은 아니지만, 정말 심하게 때가 탄 카드도 있습니다. 카드를 청소 테이블로 가져가 먼지투성이 카드가 매끈하고 반짝이는 아름다운 수집품으로 되살아나는 모습을 지켜보세요.

카드를 모으고 닦는 것만으로는 충분하지 않습니다. 모든 카드를 제자리에 정리해야 합니다. 각 카드를 올바른 세트 진열장, 아키타입 진열장, 카드 홀더에 배치하세요. 카드를 꼼꼼히 확인하고 어디에 속하는지 판단해 보세요!

Hello everyone, today it's a bigger update. Here are the new changes: - Added NewGame+ progression. When you complete the full room, now you have the option to start a NG+, with no limits to the count of NG+ you can do. NG+ unlocks 2 new upgrades (Multiple Focus and XP Gain) and removes the level limit to all upgrades (except cleaning table). - Added a new hardmode option, which you can play the same game where all the cards are grayscale. If you thought the game was too easy, now you can play the hardmode! - Special card cabinets do not get locked after they get completed. However they still cannot be exploited, so don't try to :). - Gather update: Previously, gather only worked with the cards that have never been touched before. This created a problem if you had organized the cards by taking and throwing them into a spesific place. Now, the "Gather Lock" disappears after 60 seconds for each taken card. - Fixed the brightness issue with lighter colored card sets (such as Divine and Solar). - Fixed the lagging problem that appeared when a CardHolder was completed. - Fixed the problem where the thrown cards get instantly teleported into another location if thrown
