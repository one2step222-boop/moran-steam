Version 1.21 is live!

한글 요약이 품질 관문에 걸려 원문만 둡니다.

원문 보기

Version 1.21 of Carly and the Reaperman has finally been released. This release contains a few new things and a lot of fixes: Translation to German, French, Spanish, Russian, Brazilian Portuguese, Chinese, Korean and Japanese (in addition to the previously available English and Swedish) Better support for Knuckles (see below) A lot of levels that were to easy or to hard when playing single player have been fixed so that the game is more enjoyable regardless of how you play it Fixed an issue where the game would have a weird resolution after upgrading to a newer version of Windows A lot of other bug fixes and performance tweaks The new version sadly also removes one feature - Ambient Occlusion. The reason for this is that the new version of Unity (the game engine used for the game) used to build this version removed support for AO in VR. We are sad for this and we are actively working to find a solution. Better Knuckles support In order for Knuckles (Valve Index Controlelrs) to work properly with the new version you will need to use our bindings. While Knuckles did work semi-ok before when playing coop, playing single-player did not work at all. Our bindings aim to fix that. To use
