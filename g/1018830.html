With the upcoming 5th year anniversary of Element TD 2, it felt time to release something meaty. We've pushed an alpha build that adds Peer To Peer Networking support. Both public and LAN options are available. Public is for playing with anyone. LAN is for private lobbies within an internal network. It's seamless, just select the appropriate region in game settings. When you do so, a small application is launched in the background (ElementServer.exe). This is a build of the game server running on your computer. If Windows asks for internet/firewall access, please allow it. For those concerned about privacy, it uses the same port as Steam. And if you don't want it running, just change your region back to something non-P2P and the server will be stopped. It only runs when you have set the region to P2P.
