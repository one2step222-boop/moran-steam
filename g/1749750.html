Hello doods, We have an update for you! Changes: Fixed an issue where certain controller-like hardware was being taken as the first controller over the expected controller. If you are experiencing crashes, go to C:\Users\ \AppData\Roaming\Nippon Ichi Software, Inc\Disgaea 6 Complete\, open the ID folder inside, and find the Setting.ini file, and add the following text: CrashDumpLevel = 2 The game will then produce crash dumps in the game local files. Happy dungeoning!
