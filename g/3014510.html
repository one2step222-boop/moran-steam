어떤 게임인가

Spaced Liberation is my very first game, and it's a very small indie game about the liberation of a planet. In this game, you control a turret with the sole mission to take out as much obstruction of liberty as you can possibly master. This game is currently very barebones, but I'll continuously add features over time. The only currently available game mode is a top-down stationary infinite shooter.
