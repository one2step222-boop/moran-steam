Small patch: added some new settings!

원문 보기

A couple people reported that they got dizzy and/or nauseous when playing Grunn, so I added some new settings: Wobbly effect: Toggles on/off the effect that makes everything slightly move & appear dreamy/wobbly. Pixel smoothing: Toggles on/off the fuzzy smoothing effect of pixels. Pixel scale: You can increase this to make the game appear less chunky, more smooth. Font type: Added 2 new fonts that are hopefully a bit more legible, please feel free to let me know if this helps, I can always add more fonts! You can find all of these new settings in the title screen or when pausing the game, under 'settings'. Some other things you can try against getting dizzy (also in settings): Increase the field of view. Decrease the color shift value. One other thing: There were also reports of the game looking incredibly fuzzy and weirdly low-res on ultra wide monitors, and I believe I've also fixed this issue! Thanks for playing my demo :) Let me know if this helps or if there is anything else I can add that could improve the experience! -Tom
