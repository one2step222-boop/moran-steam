어떤 게임인가

세상을 파괴하고, 죄책감에서 벗어나라.당신은 사라(Sara)입니다. 의문의 교통사고 후, 당신은 비극적인 실수로부터 도망치기 위해 무의식적으로 만들어낸 기괴하고 초현실적인 세계에 갇힌 채 깨어납니다. 이곳은 안식처가 아니라 당신이 스스로 만든 감옥입니다. 진실을 마주하는 대신, 당신은 다른 길을 선택합니다: 바로 파괴입니다.
EDGE OF DESTRUCTION은 단 하나의 강력한 메커니즘인 완전한 환경 파괴를 중심으로 구축된 싱글 플레이어 FPS입니다. 부정의 벽을 허물고, 세상을 조각조각 산산조각 내며 당신이 저지른 일의 소름 끼치는 메아리와 마주하세요.
이것은 평범한 슈팅 게임이 아닙니다. 강렬함, 의미, 그리고 완전한 혼돈을 원하는 플레이어들을 위해 정교하게 제작된 감성적이고 분위기 있는 여정입니다.

· 🎬 시네마틱 SF 스릴러: 흥미진진한 서사에 몰입하세요. 풍부한 분위기, 감정적 긴장감, 그리고 현실의 경계에 도전하는 초현실적인 SF 요소의 대담한 조화.

· ⚔️ 정교한 보스전: 전투 중 환경을 능동적으로 변화시키고 진화시키는 역동적이고 잊지 못할 보스 전투에 참여하세요. 불필요한 요소 없이 순수하고 강렬하며 정교하게 설계된 순간들을 선사합니다.

Major Update: New destruction engine

한글 요약이 품질 관문에 걸려 원문만 둡니다.

원문 보기

There are a lot changed in the new update, it is 1 GB heavier than the previous versions and there is a good reason for that. We are now using the chaos engine to calculate the destruction and that changed everything instead of the custom system I had created myself. There is a video attached below that shows the early work in progress of the new system. Please note that the demo is still not updated and I will fix the demo next week. Another big change is the rendering. We used to have ray tracing which messed up the performance on older gpus or steam deck. it is gone now. We use a pretty low cost screen space distance field to simulate global illumnation instead of ray tracing which is significantly cheaper. We then use the frame rate we won to calculate the newly added destruction engine. in my last tests on an old laptop with a 3060 RTX on ultra graphics settings, the game runs at around 70 fps with dips to 50 fps in very heavy scenes during the stress test.
