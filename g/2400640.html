원문 보기

Further fixes for NanoApostle, thank you all for the continued feedback. Players: Optimized the shooting and aiming experience. Commander: Fixed some visual effect display and damage detection errors for Commander. Attempted to fix an issue where Commander could get stuck during phase transitions. (Still under observation, if this error occurs, please report it using F10, thank you.) Kurozan: Deactivated the damage detection for explosion attacks earlier. Fixed a bug where the phase 3 cutscene for Kurozan was interrupted by actions. Adjusted Kurozan's combat experience, including reducing the execution time of Iai Slash in phase 3. Wenny: Fixed an issue where players could no longer speak with Wenny after clearing the game. Added a new interaction to hug Wenny in the later stages of the game. Other: Boss health will no longer display as 00.0% when it’s extremely low. Fixed the timing for some Boss music triggers. Level Achievement progress will now be displayed in real-time in the pause menu. Fixed an issue where certain Level Achievements based on taking fewer hits were not correctly achieved. Added a Bug Report button in the pause menu.
