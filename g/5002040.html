StellaCore 1.0.4 — Upgrade Tree Fixes

원문 보기

UPGRADE SCREEN FIXES • No more phantom connection lines. The upgrade map used to draw a link to nodes that had not appeared yet, leaving a line running off to an empty spot. Some upgrades could show up earlier than intended: - Health Multiplier +25% now requires Health +4 only — the old second link formed a loop with Player Size −12.5%. - Player Size −12.5% unlocks after Health Multiplier +25%, as intended. - Removed leftover duplicate prerequisites on Damage Multiplier 20%, Time Between Bullets −30%, Extra Bullet II and Health Regeneration II. • Links refresh instantly. Buying, unlocking or resetting upgrades now updates the connection lines right away, so the map never shows stale links. NOTES • No save format changes — existing progress carries over. • The version label in the main menu now reads 1.0.4.
