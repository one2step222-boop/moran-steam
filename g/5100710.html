Patch #4 - Mouse Movement Toggle + Bug fixes

한글 요약이 품질 관문에 걸려 원문만 둡니다.

원문 보기

-Added the option to control the player using your mouse. There is a toggle inside settings, having this toggle on will make the player move by holding down left click. -Fixed a tiny visual bug that would appear under the “Unlock Orbital” price text. The price text would stretch out in a weird way if you quickly switch between orbitals. -Fixed a bug where the golden arrow spawn chance displayed the wrong percentage on the skill tree tooltip. This was only a visual bug and did not impact the arrow spawn chance. -Fixed a funny bug where if you simply press and hold W or move the left joystick upwards on a controller right as you open the game, you will move the player up the map even though you are in the main menu. This means that you can trigger the boss inside the main menu. -There were a few variables that did not reset when you reset the entire game, these should now also reset. -Did some minor adjustments to some non English language texts.

Patch #3 - Controller support!

원문 보기

Controller support is now added! Although this was quite the challenge, you should now be able to play the game with a controller. The game has been tested thoroughly with an Xbox controller and a PS5 controller. If you find any issues when using a controller, please let me know, as this is the first time I've ever worked on controller support so there might be some polish that still need to be done. This patch also includes some balance changes. Some upgrades like damage and orbital speed has been improved. But a big change I've done is that on every level, each enemy now requires a higher total difficulty percentage before spawning.
