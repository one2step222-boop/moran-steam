Upon booting this game after updating the game will disable the Vignette/CRT shader which has been the cause of a lot of visibility issues in Battlefall. If you wish to re-enable this setting, it can be found in Options > Graphical Settings > Enable/Disable CRT Shader -- both in the Main menu and Pause menu.
