The issue Some player groups ended up in matches where no interaction worked at all: doors, chests, searching, voting… everything was unresponsive, even though movement still worked. The cause Players running different versions of the game (the September beta and the launch build) could join the same lobby through invites or the friends list. The game accepted the connection without any warning, but the incompatible versions silently broke all networking. The fix The game now refuses to join any lobby running a different version, with a clear message asking you to update. Version bumped to 1.4: make sure everyone in your group is fully updated before starting a match. What you need to do Make sure Veillombre is up to date (restart Steam if the update doesn't start).
