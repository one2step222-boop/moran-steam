However, if you encounter any game breaking issue, please use the in-game feedback button to report it to us. As a compatibility measure, we created the "legacy" branch on Steam that has the old version (1.22.4-rc.7) on it. This allows you to switch back to continue playing while waiting for a fix for the new version. Thanks again for bearing with us as we update our tools and engines. The old Levelhead version was built back in 2022, and bringing it up to date with modern tools has been a long journey for us. Hopefully, this will make future updates and bug fixes easier to deliver, and we can continue to enjoy the creative levels built by the community for more years to come!
