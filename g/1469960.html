The FPS Fixing Update
  • 물리 엔진 속도 조정 완료, 최대 75FPS 제한 플러그인 적용
  • 초기 개발 시 75FPS 기준 설정 후, 고해상도 모니터 사용 시 속도 불일치 문제 해결
  • 현재 설정으로 게임 정확한 속도 경험 가능하도록 개선
원문 보기

Hello, guys! One of the biggest struggles of Explosive Candy World was getting the physics engine to run at the intended speed. When I started developing this game, I had a monitor that only went up to 75FPS. So I programmed all of the game's speed without taking into account bigger framerates (too bad on my part haha). Soon after release, I bought a monitor that could go up to 144FPS, and was shocked to see that this game ran at lightning speed! It didn't run at the intended speed! That was very frustrating, so I tried for some time to get this fixed, but with no success. But now, it IS fixed! I applied a plugin that limits the game's FPS, so it can't go over 75FPS. This is a little problematic for people who are used to high framerate monitors, but unfortunately that is the only solution possible. Because right now everyone running the game at over 75FPS is getting an accelerated experience, like Sonic the Hedgehog, which is not the pace intended for Explosive Candy World. Hopefully everyone enjoys this update and can experience the game again at the correct speed! Thanks for playing!

Hey guys! Thanks for supporting my working and playing Explosive Candy World. Hope you are having fun with the game! So, an issue came to my attention regarding monitors with higher refresh rates. I didn't know this was happening because at the time I had a 75hz monitor, and recently upgraded to a 144hz one which made me realize the issue. If your monitor has 144 refresh rate the game will start with an absurd speed, and will gradually slow down to the correct speed. I honestly don't know why this happens, and since I only got to know this a whole year after the game's release (and had to find out myself) I suspect this isn't a big issue for the players who experience it. So if you're having trouble with the game's speed, try the following: - Run the game and wait for about 15 seconds so the speed normalizes - Or simply change your monitor refresh rate settings. I tested it at 84hz and it ran pretty smoothly! TLDR If your computer has a higher refresh rate than 75hz it is possible you'll experience some acceleration in the game.
