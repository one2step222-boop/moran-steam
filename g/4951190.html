Konbini Cleanup은 어질러진 일본 편의점을 다시 정돈하는 아늑한 정리 시뮬레이터입니다. 음료, 라면, 사탕, 과자 등 15개 이상의 구역에 걸쳐 2,928개의 상품을 분류하세요. 모든 것을 나만의 속도로 진행할 수 있습니다.
편안한 편의점 정리 시뮬레이터
가게가 엉망이라 정리가 필요합니다. 타이머도 압박도 없이, 나만의 속도로 상품을 선반에 되돌려 놓으세요.
각 상품을 집어 알맞은 구역을 찾아 올바른 가격표 아래에 놓으세요. 그게 전부입니다. 선반을 하나씩 정리하며 가게를 차근차근 정돈하면 됩니다.

플레이하면서 업그레이드를 획득하세요. 이동 속도와 도달 범위를 늘리고, 가게를 더 빠르게 정리할 수 있는 몇 가지 고유 능력을 잠금 해제하세요.

텅 빈 선반이 가지런한 오니기리 줄로 채워지고, 어지럽던 잡지 진열대는 깔끔한 더미로 정리됩니다. 완성된 구역마다 진행 상황이 한눈에 보입니다.

Crash Fix #1!

한글 요약이 품질 관문에 걸려 원문만 둡니다.

원문 보기

Hey everyone! I've made a couple of changes to the way Konbini Cleanup launches, and hopefully that will help anyone who is crashing at launch to be able to actually play the game. When you launch the game, you should now see a box that asks you to choose between "Default" and "DX11 (Use If Crashing)". If you are crashing on launch every time, try the DX11 option, and let me know how it goes. Previously DX11 looked very dark and quite buggy. This is due to the fact that when the game runs on DX11 (software that gets different parts of your PC talking to each other), the game's lighting system doesn't function like it normally does. I've fixed it quite a bit, and now it should look a bit better than it did before. I'm going to continue tweaking the DX11 look, and get it as good as I can. If you have been using DX11, let me know what I can do to make it look better for you. Whether that's brightness changes, fewer or more reflections, etc. If you are using -vulkan to launch, you should still be able to do this by leaving the -vulkan launch option in the properties. However, leaving -vulkan in and selecting DX11 will result in a crash.
