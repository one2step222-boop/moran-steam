Hi everyone, we released an update v3.6.1 late last week, and incase you were wondering what it's about, it is a hotfix patch that is intended to mitigate cases of save data corruption that could occur on Windows machines.Essentially, this hotfix enforces save files to be encoded as UTF-8, instead of letting Windows infer the encoding type; there were rare cases where Windows could incorrectly interpret the save file as a legacy encoding type (ANSI), leading to the data becoming corrupted as it was read in the wrong format.We are monitoring for issues related to this fix, and so far so good! If you do encounter a corrupted save file, please don't hesitate to reach out to us at support@maxinferno.com with details as to how the corruption occurred, and we'll look into it. Thanks!
