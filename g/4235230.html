Steam Deck Support & Localization Update

원문 보기

This update brings Steam Deck support along with several new localizations. We have optimized memory handling, allowing the game to run stably on Steam Deck. For the best compatibility, please use Proton Experimental and enable FSR. We also recommend setting the UMA Frame Buffer Size to 4 GB. To do this: - Power off your Steam Deck. - Turn it on while holding the Volume + button. - Open Setup Utility. - Go to the Advanced section. - Set UMA Frame Buffer Size to 4 GB. - Select Save and Exit. After these changes, the game should run correctly on Steam Deck. Added localizations: - Finnish - Greek - Romanian Thank you for your continued support, and have fun!

Fixed a Freeze Issue: We completely removed an unused Chromium / CEF subsystem from the game. This background component was causing conflicts with certain graphics drivers, which caused the game to freeze (hard lock) without generating a crash log. Removing this unused module cleans up background processes, improves startup times, and permanently prevents this specific GPU conflict.
