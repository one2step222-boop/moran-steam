RepliCUBE는 3D 복셀 기반 오브젝트를 복제하기 위한 코드를 작성하는 오픈엔드형 프로그래밍 퍼즐 게임/토이입니다.
퍼즐 풀기게임의 핵심 콘텐츠는 참조 오브젝트와 동일한 형태를 만들어 내는 코드를 고민해 작성하는 것입니다. "정답"은 하나가 아닙니다. 코드가 같은 오브젝트를 만들어 낸다면, 그것이 바로 정답입니다!
자유롭게 즐기기언제든지 복셀 도구를 "자유 편집" 모드로 열어, 원하는 것을 마음껏 만들어 볼 수 있습니다. 메인 3D 복셀 편집기뿐만 아니라, 코드를 사용해 2D 이미지와 GIF 애니메이션을 생성할 수 있는 보너스 2D 이미지 편집기도 제공됩니다. 이렇게 만든 이미지는 게임의 "OS" 인터페이스에서 배경 이미지로 저장할 수도 있습니다!
커뮤니티에 참여하기모든 퍼즐에는 두 개의 리더보드가 있으며, 하나는 소스 코드 크기, 다른 하나는 실행 효율을 기준으로 측정됩니다. 보통 하나를 최적화하면 다른 하나가 희생되는 경우가 많습니다. 코드에서 조금이라도 더 짜내는 과정이 즐겁다면, 리더보드가 여러분을 기다리고 있습니다!

게임 안에는 플레이어들이 직접 만든 복셀 창작물을 공유하고, 다른 플레이어에게 이를 다시 만들어 보도록 도전장을 내밀 수 있는 온라인 포럼도 있습니다. 이 모든 것은 올드스쿨 온라인 포럼 스타일의 UI로 제공됩니다.
창작물 내보내기생성된 3D 복셀 오브젝트는 다른 3D 제작 도구에서 사용할 수 있도록 일반적인 파일 형식으로 내보낼 수 있습니다.

생성된 2D 이미지와 애니메이션 역시 PNG 또는 GIF 형식으로 내보내 온라인에서 공유할 수 있습니다.
