Stellacore: Mining Odyssey is a fast-paced 2D space shooter and mining hybrid. Take the helm of a nimble starfighter in a frontier mining sector overrun by hostile, block-built machines. Patch 1.0.6 - Enemy Attacks Reworked

원문 보기

Enemy attacks, reworkedEnemy fire is now driven by difficulty tier. Normal, elite and boss encounters use the same rules, so the ramp from the first stages to the late ones is finally consistent. What changed - Tier scaling: each enemy's attack duration, fire rate, bullet count, spacing and bullet speed now scale from T1 to T8, so higher tiers fire more, faster and for longer. - Bullet speed is a per-pattern value now, no longer a fixed constant, so different patterns get different pacing. - A full pass over the roster: normal, elite and boss enemies were all rebased on the new numbers. - Faster yellow-family enemies: their movement speed and bullet speed were raised, so they apply pressure earlier. - Attack duration is capped at 10 seconds per pattern, keeping fights readable. Notes Existing saves, upgrades and achievements carry over. No progress reset.

StellaCore 1.0.4 — Upgrade Tree Fixes

한글 요약이 품질 관문에 걸려 원문만 둡니다.

원문 보기

UPGRADE SCREEN FIXES • No more phantom connection lines. The upgrade map used to draw a link to nodes that had not appeared yet, leaving a line running off to an empty spot. A connection is now only drawn when both upgrade nodes are visible. • Prerequisites corrected. Some upgrades could show up earlier than intended: - Health Multiplier +25% now requires Health +4 only — the old second link formed a loop with Player Size −12.5%. - Player Size −12.5% unlocks after Health Multiplier +25%, as intended. - Removed leftover duplicate prerequisites on Damage Multiplier 20%, Time Between Bullets −30%, Extra Bullet II and Health Regeneration II. • Links refresh instantly. Buying, unlocking or resetting upgrades now updates the connection lines right away, so the map never shows stale links. NOTES • No save format changes — existing progress carries over. • The version label in the main menu now reads 1.0.4.
