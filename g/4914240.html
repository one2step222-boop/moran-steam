👁️ 무언가 창문을 두드린다

발밑도 조심하세요: 바닥 환풍구 너머 노란 두 눈은 덕트에서 여러분을 지켜보고 있다는 뜻입니다. 머뭇거리지 마세요. 아니면 판자를 박으세요.

The issue Some player groups ended up in matches where no interaction worked at all: doors, chests, searching, voting… everything was unresponsive, even though movement still worked. The cause Players running different versions of the game (the September beta and the launch build) could join the same lobby through invites or the friends list. The game accepted the connection without any warning, but the incompatible versions silently broke all networking. The fix The game now refuses to join any lobby running a different version, with a clear message asking you to update.
