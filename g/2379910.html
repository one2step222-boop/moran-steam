원문 보기

This update adds several requested quality of life improvements as well as support for the 1.2.1 ModKit update. Quality of LifeAutosave can now be enabled in the settings at various time increments.Autoload Last Save can now be disabled in the settings. Doing so will display the Load City screen at startup instead of autoloading the most recent save. Mod Debug tools can now be activated in the settings which will display names/IDs of objects and allow for specific buildings to be selected from a building picker list. Intended for our Mod Community to help debug their creations but also useful for power users who want to select specific buildings. When a city has failed to load at startup, it will now present the City Loading screen to select or create a new city. This should prevent soft lock if a city file becomes corrupted.
