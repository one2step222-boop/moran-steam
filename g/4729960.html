어떤 게임인가

Orbit Breaker는 도형 코어, 자동 무기, 패시브 조합으로 살아남는 탑다운 생존 액션 게임입니다.
전투는 자동으로 이루어지지만 생존은 자동이 아닙니다. 플레이어는 이동, 회피, 위치 선정, 업그레이드 선택에 집중해야 합니다. 각 코어는 전용 무기와 성장 방향이 다르며, 무기와 같은 계열의 패시브를 맞추면 더 강한 진화 장비로 발전합니다.
스테이지는 단순한 빈 전장이 아닙니다. 연결된 섹터를 이동하며 숨겨진 해금을 찾고, 각 방의 파수꾼과 시간대별 적 압박을 넘긴 뒤, 마지막 보스를 쓰러뜨려야 클리어됩니다.
죽어도 끝이 아닙니다. 얻은 골드로 영구 파워업을 구매하고, 새 코어와 무기, 패시브, 스테이지를 열어 다음 출격을 준비하세요.

## 주요 특징
- 전용 시작 무기를 가진 도형 코어
- 자동 공격과 직접 회피가 맞물리는 생존 전투
- 무기와 패시브가 연결되는 진화 조합
- 숨겨진 보상, 파수꾼, 중간 보스, 최종 보스가 있는 섹터형 스테이지
- 골드로 구매하는 영구 파워업과 확장되는 장비 슬롯
- 4개의 세이브 슬롯, 플레이 기록, 무기별 피해량 리포트
- 한국어와 영어를 포함한 다국어 UI
